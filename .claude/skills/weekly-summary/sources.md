# Weekly summary — source catalog

This is the curated set of credible sources the `weekly-summary` skill searches
each Friday across **AI, Technology, HR, and strategy**. The skill ranks stories
by **cross-citation count** across these sources; a story covered by two or
more of the names below clears the bar.

Sources are grouped, not strictly ranked — different stories surface across
different tiers in a given week. The skill should sweep all four groups before
selecting picks.

## Discovery rules

The skill MAY add a new source to **Auto-discovered sources** below when ALL of the following are true:

1. The source published the story in question within the resolved week.
2. The source is a recognized firm, lab, university, government body, or
   tier-1 publication — not a personal blog, content marketing site, or
   press-release aggregator.
3. The story is independently cross-cited by at least one source already in
   the catalog above (so the new source is corroborating, not the sole
   citation).
4. The source is reachable via WebFetch (so future runs can verify).

When you add a discovered source, mention it in the final report to the user
so they can audit the growing catalog.
